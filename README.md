# TrustVault
TrustVault

Secure Document Sharing with a Real Audit Trail

About the Project

TrustVault is a secure document-sharing platform designed to protect confidential documents through document-level permissions, authentication and tamper-evident audit logging.

Technology Stack

- Python
- Flask
- HTML, CSS and JavaScript
- SQLite
- Git and GitHub

Main Features

- User authentication
- Administrator, Owner and Viewer roles
- Secure document upload
- Document-level access permissions
- Permission revocation
- Secure document downloads
- Audit logging
- Document search
- Administrative activity dashboard

Security

TrustVault uses server-side authorisation, private file storage, password hashing and audit logging.
